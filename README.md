# Sergio Alda · Portfolio interactivo

Portfolio interactivo creado con React, TypeScript, Vite y Zustand. Publicado en
[GitHub Pages](https://sergioalda06-web.github.io/my-landingpage/).

## Desarrollo local

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```

Vite genera el sitio estático en `dist/`. El workflow de GitHub Actions publica
ese directorio en GitHub Pages cada vez que hay cambios en `main`.
